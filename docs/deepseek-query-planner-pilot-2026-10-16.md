# DeepSeek 检索词助手：两主题试运行

日期：2026-10-16。此为独立对照试验，**未更新监控任务、数据库、插件包或每日调度配置**；生成的词未自动进入生产采集。

## 方法

使用项目已配置的 DeepSeek 密钥，对“具身智能”“军事智能体”各调用三次 `deepseek-flash` JSON Output，共六次；其中一次为单主题探测，另两次用于两轮 RSS 对照。只发送主题词和规则，不外发采集文章。平台端校验结构、词数、长度、重复词和控制字符；生成词默认禁用，只有脚本中人工列出的表达可参与试验，`related` 类一律不自动启用。

从两个任务当前配置的 32 个 RSS 订阅地址读取一次快照，再在同一快照上分别运行现有词表与加入审核候选词的词表。31 个订阅可解析；联合国新闻中文订阅返回内容不被当前插件识别为 RSS/Atom，因此没有参加对照。该失败属于订阅可用性，不是 DeepSeek 生成错误。

| 主题 | 现有词表命中 | 扩展词表命中 | 新增 |
| --- | ---: | ---: | ---: |
| 具身智能 | 173 | 173 | 0 |
| 军事智能体 | 72 | 72 | 0 |

较窄的第一轮审核词表同样为 173→173、72→72。现有任务已分别配置英文别名、额外关键词和组合条件，因此在这批 RSS 列表里，模型提供的等价表达没有额外召回。不能据此推断扩词对其他主题、Google 新闻原生搜索或未来新增订阅都无效；本次也没有评估新增文章的相关性，因为新增为零。

## 风险与结论

首轮模型曾将“具身认知”“实体智能”“physical intelligence”和“combat agent”放进近义词。这些词可能扩大主题或产生歧义，不能依赖 JSON 格式正确就自动启用。改进提示后仍可出现较宽的“作战智能体”“embodied agents”等候选，人工审核门槛仍有必要。

当前建议保留已有手工词表和每天 09:00 的任务，不启用 AI 自动扩词。`crawler_platform/query_planner.py` 与 `scripts/evaluate_query_expansion.py` 提供了可重复的生成、验证、人工批准和同批 RSS 对照原型；完整平台接入仍需计划持久化、人工审核界面和运行快照，不能把本次脚本试验称为已上线。

官方 API 约定参见 [DeepSeek 首次调用](https://api-docs.deepseek.com/) 和 [JSON Output](https://api-docs.deepseek.com/guides/json_mode/)。
