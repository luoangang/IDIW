# 新浪新闻搜索采集包

通过新浪搜索的新闻接口按监控任务关键词采集新闻列表。本包只使用 Python 标准库，无第三方依赖，也不需要密钥。

## 参数

- `sort`：新浪搜索排序方式，默认 `0`；可选 `0`、`1`。
- `page_size`：每次接口请求的条数，默认 `10`，范围 `1`～`50`。
- `max_pages`：单次平台执行最多访问的结果页数，默认 `10`，范围 `1`～`100`。

包会清理标题中的搜索高亮 HTML，使用 `dataid` 作为稳定来源编号，把新浪返回的北京时间转换为 UTC，并支持平台的 `time_range` 和分页游标。它采集搜索列表元数据和摘要，不抓取新闻正文。

## 导入

```powershell
.\.venv\Scripts\python.exe -X utf8 platform_main.py import crawler_packages\sina_news
```

新浪接口属于外部服务，接口策略或字段变化时可能需要升级本包。使用方应遵守新浪网站条款及适用法律，并控制采集频率。
