# Google 新闻 RSS 工具包

根据关键词、语言和地区生成 Google 新闻 RSS 查询，输出标题、来源、摘要和发布时间。

从 1.0.3 起，`query` 与 `aliases` 均参与检索：每个去重后的词或短语单独请求 RSS，再轮流合并结果，按来源编号及相同 URL 去重。`limit` 是所有检索词合计的总上限，不会因别名数量增加而倍增；没有别名时保留单关键词行为。各词使用相同的语言和地区配置，英文别名不会自动切换地区。

请求数等于去重后的主关键词与别名数量，最多 31 次；每次请求最多等待 20 秒，并受平台 `deadline_at` 截止时间限制。某个词失败或接近截止时间时，保留已取得的数据并返回 `partial` 和具体警告；全部检索失败才返回 `failed`。运行日志会列出每个实际检索词、返回数和合并总数。

这里是多词检索结果的并集，不是统一的 AND/NOT 检索引擎；各检索短语由 Google 自身规则解释。历史数据和已有任务参数无需迁移，升级包后新运行使用修正后的逻辑。
