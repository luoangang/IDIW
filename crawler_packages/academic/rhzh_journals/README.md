# 仁和汇智中文期刊检索包

一个包、一张结果表；`journals.json` 当前 318 家（包版本 1.3.4）：原 122 家按词实测刊，加 2026-11-21 当期目次验证补入的 18 家、2026-11-22/24/25 核心目录补录的 177 家，以及 2026-11-26 补入的《农业现代化研究》（`00796374865b63f7`，当期 26 条、首篇与摘要复核通过）；这些刊目前只验证了当期模式。支持 JSON `searchResult`、HTML 检索页和 `search-data` 变体。默认《工程科学学报》（`b11e9e7fdb08aa16`）；该站首轮与无关词测试通过，三条记录复测曾有一次超时。其余候选及每刊结论保存在 `journal_catalog/supplier-journal-audit-2026-10-26.csv`。

参数：`journal_keys` 最多 30 家，`collect_mode` 可选 `keywords`（默认）或 `latest_issue`（读取期刊当期文章列表），`per_journal_limit` 控制每刊数量；整次运行还受平台 `request.limit` 总上限约束，达到总上限后不再查询后续期刊。`timeout_seconds` 控制单请求超时。查询词来自 `request.query`，`latest_issue` 模式忽略查询词。当期模式会尝试 `/cn/article/current`、`/article/current` 和 `/cn/article/latest`，解析与 HTML 检索页相同的 `article-list` 结构。同一接口可能混排多期（如《复合材料学报》`current-data` 一次返回 603 条，含 552 条最新录用/网络首发），因此解析后按每条记录的年份与期号（取不到时从标题或引用行的“年,卷(期)”提取）只保留最新一期；最新录用/网络首发在存在正式当期时剔除，未排期且无法判定期次的条目保留并写入告警，不静默混期。若站点当期页只有占位内容（如工程科学学报），当期模式会明确告警；这类 API-only 站点暂继续使用 `keywords`，后续需要补 issue API。结果表存标题、详情 URL、作者、摘要、DOI、年份及期刊身份，按 `journal_key + external_id` 去重。摘要补采优先取详情页 `meta[name=dc.description]`（中文比 `article-abstract` 完整，含 HTML 实体时自动反转义），取不到再回退 `article-abstract`；只填空缺、不覆盖已有摘要，失败不阻断采集，固定 12 秒间隔，遇安全页或请求异常按 1.5 倍退避重试一次。不下载全文，不关闭 TLS 校验。
