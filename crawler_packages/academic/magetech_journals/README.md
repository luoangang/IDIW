# 玛格泰克中文期刊检索包

这是协议 v1.0 的 `1.1.1` 版源码包，不会随平台启动自动注册。平台中已安装的旧版不会自动升级，需要重新导入此目录或其 ZIP。

## 内含期刊

`journals.json` 只保留 98 家近期实测有文章且未在复核中发现明确检索失效的期刊。原有三家包内标识保持不变：

- 数据分析与知识发现（`data_analysis`）
- 图书情报工作（`lis`）
- 情报资料工作（`qbzl`）

默认仅选上述三家。98 家中，96 家在“研究”词容量测试中取得至少 70 条；《福建电脑》和《当代亚太》对换词及反向词有响应，但未证实可取 70 条。《当代亚太》仍有解析条数低于页面自报总数的问题。其他候选，包括 70 家分页停滞的期刊，已从可选目录移除；原始审计仍在 `journal_catalog/`。历史测试不保证站点长期可用，也不保证其余 96 家都通过了反向词过滤复核。

## 可配置参数

- `journal_keys`：本次启用的期刊，默认上述三刊；每次最多选择 30 家。目录内其他期刊使用 `journals.json` 中的 `journal_key`。
- “情报资料工作”继续使用旧包的 `qbzl` 键，结果身份保持不变。
- `max_pages_per_journal`：每个期刊、每个检索词最多读取的页数，默认 20。
- `request_delay_ms`：翻页间隔，默认 300 毫秒。

平台任务的 `limit` 是整个插件包的总返回上限，并会在本次启用的期刊之间尽量平均分配，避免单个期刊独占额度。任务的时间范围会按论文年份做二次过滤。

## 导入体验

1. 若尚未安装，执行 `python platform_main.py import crawler_packages/academic/magetech_journals`，或压缩该目录后在平台导入页上传。
2. 创建学术文献监控任务，输入检索词并选择本插件。
3. 运行后在记录及插件数据表中查看结果。

`journal_catalog/groups/` 保留供应商分类的原始依据。导入 `1.1.1` 后建议先按期刊筛选并做小批量验证，不要一次设置全部 98 家。

插件只使用 Python 标准库，不需要联网安装依赖。期刊站点结构变化或临时限流时，插件会把具体期刊错误写入 `warnings`，其他期刊仍可继续返回数据。
