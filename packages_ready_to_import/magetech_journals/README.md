# 玛格泰克中文期刊检索包

这是一个待手动导入的协议 v1.0 插件包，不会随平台启动自动注册。

## 内含期刊

- 数据分析与知识发现（`data_analysis`）
- 图书情报工作（`lis`）
- 情报资料工作（`qbzl`）

三个站点均采用玛格泰克新版期刊前端，并使用相同的高级检索接口。插件会在标题、摘要、关键词、作者、作者机构和 DOI 中检索任务主题词及其别名。

## 可配置参数

- `journal_keys`：本次启用的期刊，默认三刊全选。
- `max_pages_per_journal`：每个期刊、每个检索词最多读取的页数，默认 20。
- `request_delay_ms`：翻页间隔，默认 300 毫秒。

平台任务的 `limit` 是整个插件包的总返回上限，并会在本次启用的期刊之间尽量平均分配，避免单个期刊独占额度。任务的时间范围会按论文年份做二次过滤。

## 导入体验

1. 打开新平台 `http://127.0.0.1:8090/`。
2. 在“导入采集包”区域选择同级生成的 `magetech_journals-1.0.0.zip`。
3. 导入后创建论文监控任务，输入检索词并选择本插件。
4. 点击运行，在运行记录及插件数据表中查看结果。

插件只使用 Python 标准库，不需要联网安装依赖。期刊站点结构变化或临时限流时，插件会把具体期刊错误写入 `warnings`，其他期刊仍可继续返回数据。
